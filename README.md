## 🌱 Overview

**AURA** is a responsive, non-clinical mental wellness web application designed to help users build small, consistent habits around:

- 😊 Mood awareness
- 📔 Private journaling
- 🌬️ Breathing and grounding
- ✅ Micro-habits
- 📊 Gentle personal insights
- 🆘 Professional and crisis-support resources

AURA is intentionally designed to feel like a **supportive daily companion**, rather than a clinical or diagnostic tool.

> **Important:** AURA is a self-care and journaling application. It does not diagnose, treat, or replace professional mental-health care.

## 💡 Why AURA?

Wellness applications can sometimes feel overwhelming, clinical, or focused on perfect streaks.

AURA takes a gentler approach.

> **Small steps still count.**

The application combines a calm visual design with simple interactions that encourage users to:

- Pause
- Reflect
- Breathe
- Notice patterns
- Build manageable daily habits
- Reach out for human support when needed

# ✨ Features

## 😊 1. Mood Check-In

Quickly record how you're feeling without making the process complicated.

### Includes

- 1–5 mood scale
- Emoji-based mood selection
- Optional context tags
- Sleep
- Work
- Social
- Health
- Family
- Study
- Exercise
- Rest
- Optional personal note
- Mood history
- Calendar-style mood overview
- Mood trend visualization

The goal is awareness, not judgment.

---

## 📔 2. Private Journal

A simple space for thoughts and reflections.

### Includes

- Free-form journal entries
- Rotating guided prompts
- Searchable reflections
- Edit existing entries
- Delete entries
- Timestamped entries
- Private-by-default messaging

Example prompts:

> What felt gentle or good today?

> What's on your mind right now?

> What is one small thing you're grateful for?

---

## 🌬️ 3. Breathing & Grounding

AURA provides simple visual exercises for moments when users want to slow down and create some breathing room.

### Breathing patterns

- 🫁 Box Breathing
- 🌿 Calm Breathing
- 🌙 4–7–8 Breathing

### Includes

- Animated breathing pacer
- Inhale guidance
- Hold guidance
- Exhale guidance
- Rest guidance
- Session controls
- Interactive 5–4–3–2–1 grounding exercise
- Sensory grounding flow

---

## ✅ 4. Micro-Habit Tracker

AURA focuses on small, achievable actions instead of pressure.

Users can create and manage habits such as:

- 💧 Drink water
- 🚶 10 minute walk
- 🌙 No phone before bed
- 📖 Read for 10 minutes
- 🧘 Take a short pause

### Includes

- Add habits
- Edit habits
- Delete habits
- Daily completion
- Automatic streak calculation
- Gentle progress feedback
- Support for up to four active habits

> **There is no punishment for missing a day.**

---

## 📊 5. Insights Dashboard

AURA helps users notice patterns in the information they choose to record.

### Includes

- Recent mood trends
- Mood averages
- Mood calendar
- Context/tag observations
- Habit activity
- Recent patterns
- Gentle written observations

Example:

> "You've logged lower moods on low-sleep days."

Instead of:

> "Your sleep is causing your mental-health problems."

AURA deliberately avoids diagnostic or clinical conclusions.

---

# 🔒 Privacy First

Privacy is a core part of AURA's design.

The current prototype uses **browser-local storage** for demo persistence.

This means wellness information entered into the demo is stored locally in the user's browser rather than being sent to an AURA backend.

### The prototype does not include

- ❌ Advertising
- ❌ Third-party tracking
- ❌ Analytics scripts
- ❌ Data selling
- ❌ AI diagnosis
- ❌ AI clinical advice

### Privacy controls include

- 📥 Export wellness data
- 🗑️ Clear wellness data
- 🔐 Local browser persistence
- ℹ️ Privacy explanations

### Production architecture

For a real-world release, AURA should use:

- Secure server-side authentication
- Password hashing
- Secure session management
- Encrypted data storage
- Secure API endpoints
- Account deletion
- Data export
- Consent controls
- Appropriate security testing
- Production privacy policy

See:

[`docs/PRIVACY.md`](docs/PRIVACY.md)

# 🎨 Design Philosophy

AURA was designed around four principles.

### 🌿 Calm

Soft colors, generous whitespace, rounded surfaces and subtle transitions.

### 🤍 Human

Warm language instead of clinical terminology.

### 🔒 Private

Users should understand what happens to their data.

### 🌱 Gentle

Progress is encouraged without shame, pressure or aggressive streak warnings.
