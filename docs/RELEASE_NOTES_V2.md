# AURA V2 Release Notes 🌿

## Highlights

AURA V2 turns the original working prototype into a more complete, portfolio- and deployment-ready wellness companion.

### Product
- Refined authentication experience.
- Mood check-in and history.
- Journal prompts, search, editing, and deletion.
- Animated breathing patterns.
- Interactive grounding exercise.
- Habit management and streaks.
- Mood insights and calendar history.
- Support hub with crisis/professional resources.
- Dark mode and responsive mobile navigation.

### Privacy
- Browser-local demo storage.
- Data export and clearing controls.
- No ads, analytics, or third-party trackers.
- Explicit production-security warning.

### Engineering
- Vite production build.
- Vercel configuration.
- Netlify configuration.
- GitHub Actions build check.
- Dependabot configuration.
- Contribution, security, privacy, deployment, and GitHub setup documentation.
